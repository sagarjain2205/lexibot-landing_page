## 🌐 About the Landing Page

This repository contains the official **LexiBot landing page**, designed to introduce the platform, explain its workflow, showcase its AI capabilities, and provide users with direct access to the actual LexiBot application.

The landing page acts as the public-facing website for LexiBot.

Visitors can explore the platform and then launch the actual application through the **Live Demo** button.
